## Use a component

1. Start with a Next.js App Router, React, TypeScript, and Tailwind CSS 4 project.
2. Copy the complete component folder into your project.
3. Install the dependencies listed in that folder's README.
4. Import the folder's default export and render it. Its entry point loads its styles, font, and local feedback provider.

```tsx
import MembershipDashboard from './components/membership-dashboard';

export default function Page() {
  return <MembershipDashboard />;
}
```

Components use Next.js image imports and are not yet framework-independent React packages. Your app must configure Tailwind 4 and import its base stylesheet. All interactive data is local demonstration state. No backend is included.

## Work on the library

```sh
npm install
npm run check
```

Checks validate local file dependencies, TypeScript, and compilation of every component stylesheet. This repository contains component source and validation tooling; it is not a standalone website and has no dev server yet.

## Source ownership

This repository is intended to become the canonical component source. The portfolio currently retains its existing copies; automated consumption/synchronization is not configured yet. Avoid making independent edits in both repositories. A future integration should pin portfolio previews to an identified library revision.

## Status

Initial component collection. A shadcn-compatible registry is generated in `registry/`. Run `npm run build:registry` after source changes and commit the generated payloads. Automated portfolio integration remains planned work.

## CLI installation

In a Next.js project initialized with shadcn and Tailwind CSS 4:

```sh
npx shadcn@latest add https://raw.githubusercontent.com/abu-bakar-hasan/pinterest-inspired-components/main/registry/membership-dashboard.json
```

Replace the slug to install another component. Registry files include all component code, CSS, fonts as npm dependencies, typed embedded image modules, and license/provenance notes. Binary source images remain in each component folder.
