# Membership Dashboard

Copy this entire folder, then import its default export from `index.tsx`. Keep supporting files and assets beside it. No imports from another gallery folder or portfolio helper are required.

## Setup

Supported project baseline: Next.js App Router 16, React 19, TypeScript, and Tailwind CSS 4 configured with `@tailwindcss/postcss`. Your application stylesheet must import `tailwindcss` (including its base reset). The component imports its own stylesheet and Plus Jakarta Sans font.

Install runtime dependencies:

```sh
npm install @hugeicons/react @hugeicons/core-free-icons @fontsource-variable/plus-jakarta-sans
```

```tsx
import MembershipDashboard from './membership-dashboard';

export default function Example() {
  return <MembershipDashboard />;
}
```

## Files and customization

- `index.tsx`: complete entry point with sizing container, styles, font, and feedback provider.
- `Preview.tsx`: component markup and interaction state; supporting tab files remain local where present.
- `styles.css`: component styles, scoped helpers, feedback animation, and reduced-motion rules. Uses Tailwind 4 `@apply`.
- `PreviewToast.tsx`: local feedback provider and hook; preserved in each folder for independent copying.
- `content.ts`: gallery metadata; optional when using the component independently.
- `assets/`: abubakarhasan-components-amina.webp, abubakarhasan-components-daniel.webp, abubakarhasan-components-learning-avatar.webp, abubakarhasan-components-leo.webp.

Control the component width from your layout; its own wrapper establishes the container used by `cqw` sizing. Keep the wrapper when adapting the preview. Customize example data in the local TSX files and presentation in `styles.css`. Images use Next.js static imports; a plain React project needs an image-handling adaptation.

Interactions use local demonstration state, not a backend, and reset on reload. There is no registry installation endpoint yet.
